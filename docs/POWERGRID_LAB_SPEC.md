# POWERGRID LAB specification and delivery status

This is an additive learning workspace within AdigunPowerLab. The full owner requirements are in [`POWER GRID PROMPT.md`](../POWER%20GRID%20PROMPT.md); the original product scope remains in [`AdigunPowerLab  Pursuing Goal prompt.txt`](../AdigunPowerLab%20%20Pursuing%20Goal%20prompt.txt). Corporate branding and the existing customer-project workspace remain in place.

## Milestone 1 scope

- Header entry at the right of Search; exact `#POWERGRID` deep link, refresh, Back and Forward.
- Isolated generation → step-up transformer → transmission → step-down transformer → distribution → consumer learning schematic.
- Editable, validated component experiment comparing transmission current and conductor losses at two voltages.
- Browser-local experiment save and actual JSON/CSV exports, separate from customer projects.
- Help and Guide, four locale UI copy, documentation, numerical and browser acceptance.

## Delivery boundary

Milestone 1 implements a balanced three-phase constant-power component calculation only. It does not add a radial or meshed grid solver, geographic network, generation dispatch, live telemetry, protection study, standards approval or equipment control. Milestones 2–6 in the owner prompt remain future acceptance scope until individually implemented and evidenced.
